# Logo 3D — Société Tunisienne de Décoration

- `logo-std-couleur.glb` : couleurs du logo (orange, vert, liseré or, blanc).
- `logo-std-pierre.glb` : monochrome pierre blanche (matériaux `body` / `relief`, recolorables comme les produits).

Plaque en relief autoportante : 60,2 × 48,3 × 6,3 cm (L × H × P), mètres, Y vers le haut, posée à y = 0, face avant vers +Z.
Pièces nommées : soleil, feuille-1..3 (+ liseré), toit-gauche, toit-droit, toit-faitage, mur-gauche, mur-droit, porte, porte-poignee, fenetre, vague.
